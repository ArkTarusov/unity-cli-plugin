Declared with `RuntimeOnly = true` in the `{{PACKAGE}}` `{{VERSION}}` sources — `unity command` neither lists them nor shows their schemas. They execute against the editor server despite the flag, and they work against Player connections (`--runtime <process>` / `--runtime-path <port file>`). A version note on an entry still applies: a command compiled out on the running editor does not exist there and fails with exit code 6.
